Features

Real trained ML models — Ensemble of Random Forest + Gradient Boosting + MLP (VotingClassifier)
Image analysis — HOG-style feature extraction from X-ray, MRI, and dermoscopy images
Evaluation metrics — Accuracy, Precision, Recall, F1-Score, AUC-ROC shown per prediction
Doctor prescription — Evidence-based immediate actions, medications, lifestyle advice, follow-up and referral
REST API — Clean JSON endpoints, usable from any frontend or third-party system
One-command deploy — Render.com with Hugging Face Hub model storage

Quick Start
Prerequisites

Python 3.11+
Node.js 20+
Kaggle API key at ~/.kaggle/kaggle.json

1. Clone and install
bashgit clone https://github.com/YOUR_USERNAME/mediscan-ai.git
cd mediscan-ai

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r backend/requirements.txt
2. Download datasets and train models
bashpython scripts/download_and_train.py
Downloads 6 real Kaggle datasets and trains all models (~15–30 min). Saves .pkl files to backend/models/.
3. Start the backend
bashcd backend
python app.py
# Running on http://localhost:5000
4. Start the frontend
bashcd frontend
npm install
npm run dev
# Running on http://localhost:3000

API Reference
GET /health
Returns loaded model status.
json{
  "status": "ok",
  "models_loaded": ["diabetes", "heart", "kidney", "pneumonia", "brainTumor", "skinCancer"],
  "models_missing": []
}
POST /predict/<disease>
Tabular diseases — send JSON with clinical values:
bashcurl -X POST http://localhost:5000/predict/diabetes \
  -H "Content-Type: application/json" \
  -d '{"Pregnancies":2,"Glucose":148,"BloodPressure":72,"SkinThickness":35,
       "Insulin":168,"BMI":33.6,"DiabetesPedigreeFunction":0.627,"Age":50}'
Image diseases — send base64-encoded image:
bashcurl -X POST http://localhost:5000/predict/pneumonia \
  -H "Content-Type: application/json" \
  -d '{"image_b64":"<base64 string>"}'

Deployment
Render.com (recommended)

Push repo to GitHub
Connect repo on render.com → New Web Service
Set Root Directory to backend, Build Command to pip install -r requirements.txt, Start Command to gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120
Add a 2 GB persistent disk at /opt/render/project/src/models
Build frontend: cd frontend && npm run build then commit backend/static/

Model Training Details
All models use a soft-voting ensemble:

RandomForestClassifier (200 trees, balanced class weights)
GradientBoostingClassifier (150 estimators)
MLPClassifier (128→64 hidden layers)

Image models use HOG-style feature extraction:

Pneumonia / Brain Tumor: 288-dim grayscale features (8 stats + 64 histogram + 200 FFT + 16 block means)
Skin Cancer: 204-dim RGB features (12 channel stats + 64 histogram + 128 FFT)

To improve accuracy, replace feature extraction with a pretrained CNN (ResNet50, EfficientNet) and fine-tune on the datasets.
